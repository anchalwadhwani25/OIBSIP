# Online Examination System

A Java-based **Online Examination System** developed as part of the **OASIS INFOBYTE / SIP Java Development Internship**. The application provides a simple examination environment where users can log in, attempt multiple-choice questions, submit their answers, and view their final results.

## 📌 Project Overview

The Online Examination System allows users to authenticate themselves and participate in an online examination through a user-friendly graphical interface.

The system displays multiple-choice questions, allows users to select answers, automatically evaluates the submitted answers, and displays the final examination score.

## ✨ Features

* 🔐 **User Login**

  * User authentication
  * Login validation
  * Secure access to examination

* 📝 **Online Examination**

  * Multiple-choice questions
  * Answer selection
  * Question navigation
  * Exam submission

* 📊 **Automatic Evaluation**

  * Automatically checks submitted answers
  * Calculates the final score
  * Displays examination result

* 🛡️ **Input Validation**

  * Validates user input
  * Prevents invalid selections
  * Handles examination submission properly

* 🖥️ **User-Friendly Interface**

  * Simple graphical interface
  * Clear question and answer options
  * Result display after submission

## 🔐 Login

The user must log in before accessing the examination.

The system validates the entered login credentials and allows authenticated users to proceed to the examination.

## 📝 Examination Process

### 1. Login

The user enters the required login credentials.

### 2. Start Examination

After successful authentication, the user can start the examination.

### 3. Attempt Questions

The system displays multiple-choice questions. The user selects the appropriate answer for each question.

### 4. Submit Examination

After attempting the questions, the user submits the examination.

### 5. Calculate Result

The system automatically compares the selected answers with the correct answers and calculates the score.

### 6. Display Result

The final score/result is displayed to the user after evaluation.

## 📊 Result Calculation

The examination system evaluates the user's selected answers and calculates the total score based on the number of correct answers.

```text
Correct Answers → Score Calculation → Final Result
```

## ▶️ How to Run

1. Clone or download the repository.
2. Open the project in **IntelliJ IDEA**.
3. Make sure a compatible Java JDK is installed.
4. Open the project source files.
5. Locate the main Java class.
6. Run the application.
7. Enter the login credentials.
8. Start the examination.
9. Answer the multiple-choice questions.
10. Submit the examination.
11. View the final result.
