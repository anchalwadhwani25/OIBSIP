## 📌 Project Overview

The Online Reservation System is a Java-based application developed as part of the Oasis Infobyte Java Development Internship.

The system provides a simple graphical interface for users to log in, make reservations, view reservation details, and cancel existing reservations.

## ✨ Features

* User login system
* Online reservation/booking
* Passenger and journey details
* Reservation details management
* PNR-based reservation cancellation
* Database connectivity
* Input validation
* Confirmation messages
* User-friendly graphical interface

## 🛠️ Technologies Used

* Java
* Java Swing
* JDBC
* MySQL
* Maven
* IntelliJ IDEA

## ▶️ How to Run

1. Clone or download the repository.
2. Open the project in IntelliJ IDEA or another Java IDE.
3. Make sure Java and Maven are installed.
4. Configure the MySQL database connection used by the application.
5. Create the required database and tables.
6. Update the database credentials in the project configuration if required.
7. Run the main Java class.
8. Use the login screen to access the reservation system.

## 🔐 Login

The application uses a login system to authenticate users before accessing the reservation features.

Use the login credentials configured in the application/database.

## 📋 Main Operations

### Reservation

Users can enter the required passenger and journey information and create a reservation.

### View Reservation

The system displays reservation information after a successful booking.

### Cancellation

Users can cancel an existing reservation using the PNR/reservation details.
